# Navbar refresh button (styled)

Navbar refresh button (styled)

## Usage

``` r
dash_nav_refresh_button(
  id,
  label = "Refresh",
  icon = "rotate-right",
  class = NULL,
  ...
)
```

## Arguments

- id:

  inputId for actionButton

- label:

  Button label

- icon:

  Font Awesome icon name

- class:

  Additional classes

- ...:

  Passed to shiny::actionButton
